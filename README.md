# My Portfolio

Personal developer portfolio built with React + TypeScript + Vite, TailwindCSS and daisyUI.

## Tech Stack

- React + TypeScript via Vite
- Tailwind CSS + daisyUI
- framer-motion — scroll-triggered animations
- react-helmet-async — SEO meta tags

## Getting Started

```bash
npm install

# Dev server (port 3000)
npm start

# Production build
npm run build

# Preview production build
npm run preview
```

## Customization

All site content (name, social links, experience, projects, skills) lives in **`src/data/data.tsx`**.
